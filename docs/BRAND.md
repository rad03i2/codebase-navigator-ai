# Codebase Navigator AI Brand System

## Concept: Code Atlas

The visual identity treats a repository like a navigable map rather than a wall of source files.

The core metaphor combines:

- a **compass / radar** for navigation;
- a **code document** for repository source;
- connected **nodes** for project structure;
- concentric rings for progressively narrowing from repository → file → symbol → line context.

This gives the project a distinct identity from generic “AI assistant” graphics and from cleanup/security tools.

## Personality

- Exploratory
- Technical
- Calm
- Precise
- Developer-focused
- Local-first
- Transparent about current AI boundaries

The project should feel like an observatory for code structure, not a chatbot.

## Logo

Primary asset: `assets/project-logo.svg`

The logo combines:

1. an outer navigation ring;
2. four directional repository nodes;
3. a central source-code document;
4. a small mint focal point representing the current target in the codebase.

### Usage

- Keep the rounded-square container when used as a repository/app icon.
- Do not replace the central code file with a chat bubble.
- Do not add generic robot heads or brain silhouettes.
- Preserve high contrast around the violet document outline.
- At small sizes, use the icon without the full project name.

## Typography

Artwork uses portable system stacks:

- Latin: Inter / Segoe UI / Arial / sans-serif
- Arabic: Tahoma / Segoe UI / Arial / sans-serif
- Technical labels: ui-monospace / SFMono-Regular / Consolas / monospace

Repository Markdown should use GitHub's native typography.

## Visual language

Recommended:

- node maps;
- constellation-like repository graphs;
- concentric navigation rings;
- path lines;
- code brackets;
- focused target markers;
- subtle grid geometry.

Avoid:

- generic AI brains;
- chatbot bubbles;
- humanoid robots;
- fake neural-network claims;
- screenshots implying a GUI;
- cloud imagery that conflicts with the local-first model.

## Identity distinction

Codebase Navigator AI uses a **cartography / observatory** language with Midnight Indigo, Atlas Violet, Aqua, and Mint. Its visual promise is “find your way through a repository,” not “generate code for you.”

That distinction is especially important because the current implementation is deterministic and does not include an LLM.
